# 🚀 AI/ML Portfolio: Dual Prediction Dashboard

Is project mein maine do mukhtalif Machine Learning models ko aik hi interface par deploy kiya hai.

## 🌟 Key Features
* **🚢 Titanic Survival Predictor:** Passenger details ke mutabiq survival predict karta hai.
* **🤖 Sentiment Analyzer:** Amazon reviews ka sentiment (Positive/Negative) batata hai.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Scikit-Learn, Pandas, Joblib
* **Deployment:** Streamlit Cloud
